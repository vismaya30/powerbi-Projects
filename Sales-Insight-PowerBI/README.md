# Sales Insight Dashboard – Power BI Project

## Project Overview
This project analyzes retail sales data to identify trends in product performance, profitability, promotions, and regional sales. An interactive Power BI dashboard was built to support data-driven business decisions.

## Business Objective
Provide a consolidated view of sales and customer behavior to help stakeholders understand:
- Top and bottom performing products
- Sales trends over time
- Impact of discounts and promotions
- Profitability across products and cities

## Tools Used
- Power BI (Data modeling, DAX, dashboards)
- Excel (Source dataset)

## Key Analysis & Metrics
- Total Net Sales, Profit, Units Sold
- Number of Orders & Average Order Value
- Sales trends (daily & yearly)
- Profit vs Sales relationship
- Discount analysis by promotion category
- City-wise sales performance

## Dashboard Highlights
- Product performance analysis (Top/Bottom products)
- Trend analysis and profitability insights
- Promotion and discount effectiveness
- Geographic contribution to sales
